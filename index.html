Postman for Agents

Work with Postman from your agents.

Copy the prompt below into your agent to setup postman cli. Postman helps your agent develop, test, manage, and distribute your APIs and services. 

Set up Postman in this repository.

## 1. Install the Postman CLI

Pick the install method that matches the environment:

**npm (macOS, Linux, Windows):**
npm install -g postman-cli

**macOS / Linux / WSL:**
curl -o- "https://dl-cli.pstmn.io/install/unix.sh" | sh

**Windows (PowerShell):**
powershell.exe -NoProfile -InputFormat None -ExecutionPolicy AllSigned -Command "[System.Net.ServicePointManager]::SecurityProtocol = 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://dl-cli.pstmn.io/install/win64.ps1'))"

Verify the install:
postman --version

Docs: https://learning.postman.com/docs/postman-cli/postman-cli-installation/

## 2. Log in to Postman

Run:

postman login

Complete the browser sign-in flow when prompted.

## 3. Initialize Postman in this repo

From the repository root, run:

postman init

This scaffolds Postman config in the project (for example `.postman/` and related metadata) so collections, environments, and workspace settings can live alongside the codebase.

If the command is interactive, accept sensible defaults for this repo unless I specify otherwise. Commit any generated Postman files unless I say not to.
